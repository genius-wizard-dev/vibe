# research folder template

Root:

`.vibe/research/`

Files:

- `overview.md`
- `active.md`

Topic folder:

`.vibe/research/<research>/`

Required files:

- `state.md`
- `brief.md`
- `interview.md`
- `analysis.md`
- `discussion.md`
- `decisions.md`
- `logs.md`
- `output.md`

## state.md template

```markdown
# research state

topic: <research>
scope: local
updated_at: {datetime}

scan: pending
interview: pending
analyze: pending
discuss: pending
export: pending
```
