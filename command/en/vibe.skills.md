name: vibe.skills
description: Scan project, auto-suggest and create .agents/skills/ with context files. Flexible stack detection.
---

## Step 0: Read State & Setup

```bash
cat .vibe/state.md
mkdir -p .agents/skills .agents/context

```

- If `[SKILLS] status: ✅ done` -> show existing skills and ask "Add new skills or regenerate?"
- Write: `## [SKILLS] status: 🔄 in-progress`
- Read from state: `stack`, `domain`, `adrs`, `constraints`.

---

## Step 1: Scan Project & Propose Skills (Dynamic Detection)

> AI automatically analyzes project structure (for example: package.json, requirements.txt, go.mod...) and cross-checks with `stack` from state.

```bash
# Search and analyze skills based on detected tech stack
npx skills find <detected_tech_stack>

```

**AI workflow in this step:**

1. Read results from the command above.
2. Show the best-matching skill list for the project.
3. **Ask user:** _"Based on your project, I suggest these skills: [Skill A, Skill B, Skill C]. Should I auto-create all of them, or only specific skills you choose?"_

---

## Step 2: Create Skill Files

> AI only creates skills for tech items **confirmed** from Step 1. Skip any skill already listed in `skills: [...]` in state.

Each file `.agents/skills/{skill_name}/SKILL.md` is auto-generated by AI from this standard template:

```markdown
# Skill: {Skill Name}

> Use when: ... · Do not use when: ...

## Standard patterns (real code aligned with this project architecture)

## Implementation checklist

## Anti-patterns ❌ (mistakes to avoid for this tech)

## Examples from this project
```

✍️ After each file is created: auto-update that skill name into `skills: [...]` in state.
